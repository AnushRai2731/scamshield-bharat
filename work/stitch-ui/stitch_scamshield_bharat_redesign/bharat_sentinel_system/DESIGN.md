## Brand & Style

This design system expresses quiet authority, high-order institutional intelligence, and profound emotional reassurance. Tailored specifically for Indian multi-generational families navigating complex digital ecosystems (UPI payments, WhatsApp forward loops, automated call farms, and impersonation threats), the UI shuns cybersecurity clichés. There are no neon matrix rain overlays, command-line terminal aesthetics, lock badges with sharp spikes, or sensationalist crimson screens that induce panic. 

Instead, the aesthetic merges Modern Indian Civic Trust with Consumer FinTech Polish:
- **Tone:** Calm, protective, vigilant, dignified, and familial. It reads like an elite personal guardian who explains complex digital patterns with clarity and warmth.
- **Visual Stance:** Pristine surfaces, spacious layouts, deep naval anchoring, and warm off-white canvas foundations. Color is strictly informative and behavioral, never decorative or anxious.
- **Design Movement:** Clean Modern Humanist with Soft Elevation. It combines generous boundary radiuses, subtle micro-tonal surface fills, and deliberate negative space to deliver clarity even under moments of suspected fraud.

## Colors

The palette establishes an emotional progression from stability to vigilance.

- **Primary Canvas & Neutral Surfaces:**
  - Base Background: `#F8FAFC` (Slate 50), providing a restful, glare-free reading substrate.
  - Surface Low / Container Base: `#FFFFFF` (Pure White) with 1px hairline stroke `#E2E8F0`.
  - Surface High / Inset Elevation: `#F1F5F9` (Slate 100) for nested metadata modules and scanning trays.
  - Text Primary: `#0F172A` (Slate 900) delivers definitive contrast for legal, family, and transaction alerts.
  - Text Muted: `#64748B` (Slate 500) for timestamps, secondary labels, and descriptive body copy.

- **Brand & Action Signals:**
  - Primary Structural Anchor: `#0F172A` (Deep Navy) for primary navigation headers, security summary bars, and structural anchors.
  - Vibrant Accent: `#2563EB` (Royal Blue) for interactive controls, secondary security scanning progress, active filter states, and trusted verification badges.

- **Tri-State Behavioral Triage System:**
  - **Safe / Low-Risk:** Emerald Green (`#10B981` fill, `#059669` border/text). Signifies resolved issues, verified sender identity, safe UPI handle, and secure device states.
  - **Caution / Under Verification:** Warm Amber (`#F59E0B` fill, `#D97706` border/text). Used for unrecognized contacts, unverified links, or urgent SMS language requiring family consensus.
  - **High-Risk / Critical Threat:** Crimson Red (`#EF4444` fill, `#DC2626` border/text). Reserved exclusively for active malware signatures, identified phishing payloads, and confirmed financial fraud requests. Never used for neutral system errors.

## Typography

The type system prioritizes high-legibility geometry across varied device screen resolutions and multi-lingual Indian script pairings. 

- **Primary Family (Plus Jakarta Sans):** Selected for warm, open aperatures, geometric clarity, and friendly humanist construction. It eliminates cold robotic distance, ensuring older family members can read scan diagnostics comfortably without eye strain.
- **System & Data Labels (Inter):** Applied across numeric readouts, IP data, verification chips, status counters, and technical timestamps for absolute clarity and uniform tabular numeric layout.
- **Handling Multi-lingual Nuance:** When localized into Hindi, Tamil, Telugu, Bengali, or Marathi, maintain identical line-height metrics to prevent layout shifts. Increase body line-height by `+2px` automatically whenever regional unicode scripts are active.

## Layout & Spacing

The layout model is built upon a 12-column responsive fluid grid on desktop and tablet environments, collapsing to an adaptable 4-column framework on mobile devices.

- **Desktop (min-width: 1024px):** 12-column layout, max container width of `1280px` centered, `gutter: 1.5rem`, `margin: 2rem`. Dedicated left-hand navigational spine with persistent family member threat radar.
- **Tablet (768px - 1023px):** 8-column layout, `gutter: 1.25rem`, `margin: 1.5rem`. Secondary panels switch to collapsible bottom sheets or responsive segmented tabs.
- **Mobile (under 768px):** 4-column fluid layout, `gutter-sm: 1rem`, `margin-sm: 1rem`. Bottom navigation dock for primary thumb zone actions: "Scan", "Family Shield", "Alert Feed", and "Vault".
- **Vertical Spacing Rhythm:** Strictly enforced intervals of `4px`, `8px`, `16px`, `24px`, and `40px`. Stacked alert lists use consistent `12px` gaps to retain distinct tap targets while preserving group continuity.

## Elevation & Depth

Visual hierarchy uses layered ambient diffusion rather than harsh drop shadows, ensuring the product feels physical, clean, and featherweight.

- **Base Floor (Level 0):** Pure canvas fill `#F8FAFC` without shadow. Used for app shell foundations and side navigation backdrops.
- **Card Surface (Level 1):** `#FFFFFF` paired with an ultra-soft dual-stage ambient occlusion shadow:
  `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 4px 16px -2px rgba(15, 23, 42, 0.05);`
  Enclosed by a subtle structural border: `1px solid #E2E8F0`.
- **Floating Modals & Inspection Drawers (Level 2):** Elevated interactive planes such as Deep Scan results, incoming call overlay triggers, and family member privilege edits:
  `box-shadow: 0 10px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.03);`
- **Dynamic Threat Halo (Alert State Only):**
  When a critical item or warning is displayed, cards use soft colored edge rings rather than solid high-contrast borders:
  - Critical: `box-shadow: 0 0 0 1px #FECACA, 0 8px 24px -4px rgba(239, 68, 68, 0.12);`
  - Caution: `box-shadow: 0 0 0 1px #FDE68A, 0 8px 24px -4px rgba(245, 158, 11, 0.12);`
  - Safe: `box-shadow: 0 0 0 1px #A7F3D0, 0 8px 24px -4px rgba(16, 185, 129, 0.08);`

## Shapes

The design system embraces an approachable, reassuring form factor that softens technical cybersecurity interactions.

- **Primary Structure Cards:** Implemented with `1.25rem` (20px) to `1.5rem` (24px) border radiuses (`rounded-2xl` and `rounded-3xl` equivalents). Corners are deliberately smooth to convey warmth and avoid intimidating sharp points.
- **Inner Interactive Modules & Insets:** Inner input trays, safe-link inspection cards, and media quarantine containers adopt `0.75rem` (12px) to match inner concentric curve principles.
- **Pill Badges & Buttons:** Primary action buttons, security tags, status chips, and family member avatars adopt a fully rounded pill format (`9999px`) to maintain physical tactility and distinct interactive affordance.

## Components

- **Buttons:**
  - *Primary Action:* Deep Navy (`#0F172A`) solid background, pure white text, 14px font size, semi-bold weight. Padding: `12px 24px`, pill-shaped (`9999px`). Smooth hover elevation with transition: `transform 150ms ease, box-shadow 150ms ease`.
  - *Secondary / Assistive:* Pure white surface with hairline border (`#CBD5E1`), royal blue (`#2563EB`) text. Hover introduces soft tint (`#EFF6FF`).
  - *Critical Resolve:* High-threat action buttons utilize pure Crimson (`#DC2626`) exclusively when the direct action is destructive (e.g., "Block & Sever Connection", "Report Fraud to Bank").

- **Family Shield Status Cards:**
  - Designed as the visual anchor of the dashboard. Features large `24px` radius, subtle multi-layered ambient shadow, and an active family member roster chip strip.
  - Hosts the circular "Family Safety Index" ring: a continuous smooth SVG progress track with 8px stroke weight using Emerald (`#10B981`) for pristine states, transitioning gracefully without flashing animations.

- **Threat Assessment Chips & Verification Badges:**
  - Height: `28px`. Padding: `4px 12px`. Pill-radius.
  - *Safe Chip:* Background `#ECFDF5`, text `#065F46`, paired with an emerald micro check-shield icon.
  - *Suspicious Chip:* Background `#FFFBEB`, text `#92400E`, with an amber pulse dot.
  - *Threat Chip:* Background `#FEF2F2`, text `#991B1B`, accompanied by a clear, non-aggressive caution badge.

- **Link & SMS Inspection Input Fields:**
  - Large single-surface scanner input. Base height: `56px`. Surface fill: `#FFFFFF`. Border: `1.5px solid #E2E8F0`. Corner radius: `16px`.
  - Active focus: Border shifts to `#2563EB` with an ambient outer glow ring `rgba(37, 99, 235, 0.12)`. Features inline "Paste Clipboard" action tailored for elder users analyzing suspicious WhatsApp forwards.

- **Family Member Activity List:**
  - Clean separation using whitespace (`12px` row gaps) rather than divider rules.
  - Each row presents a circular avatar with a micro status indicator, clear localized relationship tags ("Father - Delhi", "Mother - Pune"), device integrity status, and instant "Call to Reassure" contextual triggers.

- **Scam Explanation Accordion (Bilingual/Plain Language):**
  - Card-in-card nested architecture (`#F8FAFC` inner surface, `12px` radius).
  - Translates technical fraud vectors (e.g., "APK sideload overlay attack") into plain conversational explanations ("A fake electricity bill app attempting to view OTPs") with audio play buttons for vernacular voice guidance.
